# Assets

`icon.ico` here is a **placeholder** (a plain teal square), generated so
`pnpm package:win` has a valid file to point at and doesn't fail on a
missing path. Replace it with real branding before shipping to anyone:

- Needs to be a real multi-resolution `.ico` (16/32/48/64/128/256px).
- Any online "png to ico" converter works, or `electron-icon-builder`.
- Keep the filename `icon.ico` in this folder, or update the `win.icon`
  path in `apps/desktop/package.json` if you rename it.
